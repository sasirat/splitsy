# @splitsy/design-system

Splitsy's design tokens and shared UI primitives.

- `configs/` — tokens defined in TypeScript (colors, typography, spacing) _(S3)_
- `scripts/` — generate Tailwind-compatible CSS from the configs _(S3)_
- `styles/` — generated CSS, imported by the web app

Currently a skeleton. Filled in during **S3** (extract tokens from Figma) and
**S4–S5** (build the component library).
